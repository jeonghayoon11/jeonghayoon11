## Featured Projects

### AegisFlow — API Security Gateway
인증, 요청 제한, 이상 패턴 기록을 하나의 흐름으로 관리하는 API 보안 게이트웨이. JWT 검증과 요청 제한, 정책 설정, 차단 사유를 단일 미들웨어 계층에서 처리하고, Redis로 여러 서버의 요청 횟수를 공유합니다.
`TypeScript` `Node.js` `Redis` `Security`

### OrbitOps — Deployment & Incident Dashboard
여러 리눅스 서버의 배포 상태, 장애 기록, 롤백 흐름을 한 화면에서 관리하는 운영 플랫폼. 서버 에이전트가 상태·배포 이벤트를 전송하고, Go와 WebSocket으로 실시간 대시보드를 구성했습니다.
`Go` `Linux` `Docker` `WebSocket`

### DevVault — Secure Secrets CLI
API 키와 환경 변수를 로컬에서 암호화해 보관하고 필요한 실행 환경에만 안전하게 주입하는 CLI 도구. Rust와 AES-256-GCM으로 암호문 변조까지 검증합니다.
`Rust` `AES-256-GCM` `CLI` `SQLite`

### 미세먼지 검증 시스템 — Validated IoT Air Control
공공 API의 누락·오류값까지 고려해 환기 장치를 안정적으로 제어하는 IoT 시스템. 데이터 유효성 검사와 팬 제어 로직을 설계해 비정상 응답 상황에서도 안전하게 동작하도록 구현했습니다.
`Python` `Open API` `Validation` `IoT`
