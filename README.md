**AegisFlow**
API Security Gateway

인증, 요청 제한, 이상 패턴 기록을 하나의 흐름으로 관리하는 API 보안 게이트웨이. JWT 검증과 정책 설정, 차단 사유를 단일 미들웨어 계층에서 처리하고 Redis로 여러 서버의 요청 횟수를 공유합니다.

`TypeScript` `Node.js` `Redis`

</td>
<td width="50%" valign="top">

**OrbitOps**
Deployment & Incident Dashboard

`Go` `Linux` `Docker` `WebSocket`

</td>
</tr>
<tr>

`Rust` `AES-256-GCM` `SQLite`
